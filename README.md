# 伊藤水晶 — Portfolio

React + TypeScript + Vite + Tailwind CSS + Framer Motion で構築したポートフォリオサイト。

## 開発

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

## コンテンツの編集

- **写真**: `public/profile/photo-0N.jpg` を差し替えるだけで反映されます。
- **Works**: `src/data/works.ts`
- **Journal**: `src/data/journal.ts`
- **プロフィール / Now / SNS**: `src/data/profile.ts`
- **連絡先メール**: `src/components/Contact.tsx` の `EMAIL` 定数
